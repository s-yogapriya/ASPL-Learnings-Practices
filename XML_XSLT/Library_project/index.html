How This Works

1. Data Storage
📄 library.xml Canonical XML repository storing raw book records
→
2. Transformation Layer
⚙ Node.js (XSLT Engine) Executes XSLT & XPath transformations outside the browser
→
3. User Views
📚 HTML Views / XML Export Delivered consistently to Chrome, Edge, and Firefox

XML stores the library data. XSLT transforms that data into different required views and formats on the Node.js server. JavaScript handles user interactions such as search and filters, requesting views via the transformation API.
